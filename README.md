# 写真合成エディター

複数の写真をレイヤーとして重ね、自由に切り抜き・配置・変形して合成画像を作る、**ブラウザ完結型**のWebアプリです。
画像の読み込み・編集・書き出し・プロジェクト保存はすべて端末のブラウザ内で行い、**サーバーへの送信・保存、外部API／分析／AIサービスへの通信は一切ありません**。

技術構成：React 18 / TypeScript / Vite / Fabric.js 6（レイヤーの選択・移動・変形）／ Canvas API（切り抜き・書き出し）／ File API・Blob。

## 起動方法

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）。スマホ実機確認は --host 付きで LAN 公開されます
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果を http://localhost:4173 で確認
npm test           # ユニットテスト（Vitest）
npm run e2e        # 実ブラウザ結合テスト（要: preview を起動し Chromium を用意）
```

`dist/` は静的ファイルのみ（相対パス）なので、任意の静的ホスティングに置けます。

結合テストは `playwright-core` と Chromium を使います。`npm run preview` を起動した状態で
`CHROME=/path/to/chrome node tests/e2e/run.mjs` と `node tests/e2e/mobile.mjs` を実行します（`?debug` 付き URL でのみ有効な読み取り専用フックを使用）。

## 使い方

| 操作 | 方法 |
|---|---|
| 画像を追加 | 「画像追加」、ドラッグ＆ドロップ、貼り付け（Ctrl/Cmd+V）。JPEG・PNG・WebP、複数選択可 |
| 移動・拡大縮小・回転 | 「選択」ツールで画像をタップ → ハンドル操作。数値（中心X/Y・幅・高さ・角度）でも指定可 |
| 不透明度・表示・ロック | プロパティのスライダー、レイヤー行の目／鍵ボタン |
| 順序・複製・削除 | レイヤーパネル下部のボタン（最前面／1段前／1段後ろ／最背面／複製／削除） |
| 切り抜き | 対象レイヤーを選択 → 投げ縄／多角形／四角形／楕円 → 範囲を指定 → 「適用」。範囲の外側が透明になる |
| 表示の拡大縮小・移動 | タッチ：2本指ピンチ／2本指ドラッグ。マウス：Ctrl+ホイール、ホイール、Space+ドラッグ、中ボタンドラッグ、「手のひら」ツール、画面上の＋／−／全体 |
| 保存・再編集 | 「保存」で `.photo-project` ファイル（画像を同梱）。「開く」で復元 |
| 書き出し | PNG（透明保持・標準）／JPEG（背景色を指定）／WebP（非対応ブラウザでは無効）。キャンバス実サイズで出力 |
| キャンバス設定 | 幅・高さ・背景（透明／単色）・プロジェクト名 |

### 切り抜きツール

- **投げ縄**：なぞって離すと、始点と終点が離れていても直線で閉じて範囲になります。
- **多角形**：タップ／クリックで頂点を追加。最初の点（橙）をタップするか「確定」／Enterで閉じます。「戻る」／Backspaceで直前の頂点を削除、「キャンセル」／Escで破棄。頂点はドラッグで微調整できます。
- **四角形・楕円**：ドラッグで範囲指定。
- 確定した範囲は外側が暗く表示され、明るい部分が残ります（プレビュー）。**自己交差した線は「非ゼロ巻き数」規則**で塗りつぶし、囲まれた領域はすべて残ります（プレビューと切り抜きは同じ規則）。
- 切り抜きはアルファマスク（`destination-in`）で行い、範囲外のアルファを0にします。元画像の透明は保持され、画素は再サンプリングされません。範囲の縁はアンチエイリアスされます。何度でも重ねて切り抜けます。

Ctrl/Cmd+Z 元に戻す ／ Ctrl/Cmd+Shift+Z（Ctrl+Y）やり直し ／ Delete・Backspace 削除 ／ Esc 取り消し ／ Enter 確定・適用 ／
V H L P R E ツール切替 ／ 矢印キー 1px 移動（Shiftで10px）／ Ctrl/Cmd+D 複製 ／ Ctrl/Cmd+] [ レイヤー順（Shiftで最前面・最背面）／
Ctrl/Cmd+S 保存 ／ Ctrl/Cmd+O 開く ／ Ctrl/Cmd+Shift+E 書き出し ／ Ctrl/Cmd+0 全体表示 ／ Ctrl/Cmd +/- ズーム。

## レイアウト

- **パソコン／広いタブレット（幅900px以上かつ高さ520px以上）**：左にツール、中央にキャンバス、右にプロパティとレイヤー。左右パネルは表示切替可能。
- **スマホ・縦向きの狭い画面**：キャンバス中央、下部にツールバー、レイヤー／プロパティは下からのパネル（キャンバスは縮むだけで隠れない）。
- **スマホ横**：ツールを左の2列レールに、パネルを右側に表示。
- ボタンのタップ領域は44px以上。CSP により `connect-src 'self'` で外部通信をブラウザ側でも遮断しています（本番ビルド）。

## 設計メモ

- `src/core/coords.ts`：画面／ドキュメント／元画像ピクセルの座標変換を一元化。切り抜き・書き出し・画面描画は同じ行列を使うので、ズームや端末サイズが変わっても位置はずれません。
- `src/state/history.ts`：履歴はレイヤーのメタデータのスナップショットで、ピクセルは `assetId` 参照。履歴ごとに画像を複製せず、参照されなくなったアセットだけ解放します（履歴は最大100件／約600MBで古いものから破棄）。ドラッグやスライダーの連続操作は1履歴にまとまります。
- プロジェクト形式（`src/core/project.ts`）：マジック＋バージョン＋JSON管理情報＋画像データ（元ファイル／切り抜き後はアルファ付きPNG）を連結したバイナリ。Base64を使わずBlobを連結するため大きな画像でも余分なコピーが少なく、読み込み時にマジック・バージョン・サイズ・参照整合性・画像寸法を検証します。

## テスト結果

- ユニット（Vitest）20件：座標変換、履歴（ドラッグの統合・ダーティ判定など）、プロジェクト形式（往復・破損・未来バージョン・不整合の拒否）。
- 結合（Chromium、`tests/e2e/run.mjs` 70件／`tests/e2e/mobile.mjs` 60件）：画像読み込み（PNG/JPEG/WebP・複数・不正ファイル）、レイヤー操作全般、Undo/Redo、投げ縄・多角形・四角形・楕円の切り抜き（範囲外の透明、元の透明の保持、ズーム2倍超でも位置ずれなし、切り抜き後の変形、Undo、複数回）、透明PNG／JPEG／WebPの書き出し（実サイズ、選択枠なし、非表示レイヤー除外）、プロジェクトの保存・再読み込み、外部通信ゼロの確認、スマホ縦横・タブレット縦横・PCでの操作（タッチのドラッグ・ピンチ・2本指パン・タッチ投げ縄・多角形の画面ボタン）、44px以上のボタン、横スクロールなし、ボタンの重なりなし。

## 既知の制限

- 実機のスマホ／タブレット（iOS Safari など）では未検証です。検証はChromiumのタッチエミュレーション（CDP）とビューポート指定で行いました。
- 切り抜きは画素を書き換える方式です。プロジェクトを保存・再読み込みした後に「切り抜きの取り消し」はできません（同一セッション内のUndoは可能）。必要なら切り抜き前に別名で保存してください。
- デコード済みの画像をメモリに保持するため、高解像度の写真を大量に読み込むと端末によってメモリ不足になります。1枚あたり長辺16384px・64メガピクセルまで、キャンバスは8192px・40メガピクセルまで。
- 自動保存はありません（画像をブラウザ内に残さない方針）。保存していない変更がある場合は確認ダイアログとページ離脱時の警告が出ます。
- JPEG/WebPは透明を扱えません（JPEGは背景色で塗りつぶし）。WebPの書き出しはブラウザ依存です。
- 日本語を含むファイル名は、ブラウザ・OSによってダウンロード名が変わることがあります（保存名が未設定のときは `project.photo-project` になります）。
- ブラウザの戻る／進むやスマホのOSジェスチャーとの干渉は、キャンバス領域で `touch-action: none` にして抑えていますが、画面端のOSジェスチャーは防げません。
